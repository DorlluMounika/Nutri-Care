🌿 Nutri-Care

Your Personal Health and Nutrition Guide

Nutri-Care is a web-based health and nutrition platform designed to help users make better lifestyle choices.

✨ Features

- PCOS and thyroid health guidance
- Personalized diet suggestions
- Weight management guidance
- Exercise recommendations
- Calories, protein and vitamin information
- Specialist recommendations
- Simple and user-friendly interface

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
